Protocol Security Guarantees

  • Zero-Exposure Timestamping: Only the SHA-256 digest is committed on-chain—private source files stay on your machine.
  • Deterministic IP ID & Uniqueness: Duplicate registrations of an identical content_hash are rejected at consensus level.
  • Perceptual Prior-Art Guard: A 64-bit SimHash checks existing filings for textual overlap to flag plagiarism early.
  • Automated Royalty Splits: Even after transferring IP ownership, public license purchases route royalty_bps to the original creator.
